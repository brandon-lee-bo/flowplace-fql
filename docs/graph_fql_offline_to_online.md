# FlowPlace 与 Flow-Q 的离线到在线实验

目标是在 FlowPlace 的电路表示和图网络基础上实现 Flow-Q，并利用真实后端反馈继续训练策略与 Q。`bp_fe` 的三个独立训练 seed 均已完成离线、两轮实际在线更新及最终详细布线；63/63个预定请求均成功、DRC=0。在线 FQL 平均最终线长为 **2.031445m**，比匹配 BC 的 **2.037714m** 低约 **0.308%**，但三个 seed 中有两个退步，seed 间波动也更大，尚未显示稳定 RL 优势或整体 PPA 改善。384标签组和第二电路 `bp_be` 也已完成两轮真实在线训练。384标签组最终 GRT 线长比匹配 BC 低 **1.255%**，但时序更差，同提案 Q 诊断也未显示更可靠的预测；两组最终详细布线 PPA 及第二电路最终 GRT 评分仍未完成。

首个 seed 的原定21个布局、同采集预算的最佳实测参考及增加反馈量实验均已完成统一 cap20 详细布线。两轮在线 FQL 的平均最终线长比匹配 BC 高约 **1.30%**；增加反馈量后仍未改善。反馈路径对照的20个布局也均为 DRC=0：只扩展行为 flow 数据、只扩展 Q 数据、同时扩展两者，相对固定 replay 的最终线长分别增加约 **1.108%、0.070%、1.549%**。这是单父模型、四个已观察噪声的机制诊断，不能替代独立验证。目前需要判断的是更充分的真实标签能否改善 Q 和策略，而不能用预测误差下降代替布局质量改善。

## 方法和动作定义

一次动作输出全部 11 个宏块的中心坐标，共 22 个数。电路网表固定，环境依次完成合法化、DEF 坐标取整、后端轨道对齐、标准单元放置、时钟树和全局布线，再返回真实评分。生成过程中的 flow 积分步骤不作为 RL 环境转移。

这是一个终局决策问题，终止 mask 为 0，所以 Q 的训练目标就是本次实测 reward，不对虚构的后续状态进行自举。当前 reward 为 `−全局布线线长 / 2341121.25`，分母取自离线 TRAIN，在线阶段保持不变。时序、功耗和面积分别评估，没有混入这个 reward。经核实的几何或物理失败使用效用 −4，并保留失败类别；不为失败编造 PPA。

| 部分 | 实现 | 与原方法的关系 |
| --- | --- | --- |
| 电路表示 | 宏块尺寸、连接关系和引脚偏移组成的图，以及当前坐标和时间 | 复用 FlowPlace |
| BC flow | GATv2、自注意力、MLP，预测坐标速度 | 复用约 628 万参数的 FlowPlace 骨干和预训练权重，继续 flow matching 训练 |
| 一步策略 | 独立图网络，从噪声直接输出整张布局的坐标 | Flow-Q 的策略蒸馏机制，和 BC flow 不共享权重 |
| Q 网络 | 17 个物理特征加宏坐标，两个独立的 128 宽 MLP | 适配固定电路的 critic，两者均值参与策略优化 |
| 策略目标 | `10 × 蒸馏 MSE − mean(Q1,Q2)` | Flow-Q 核心目标；匹配 BC 将 Q 项系数设为 0 |
| 动作约束 | 输出裁剪、外部合法化、实际后端宏几何检查 | 保留布局可行性检查，不宣称能够对硬合法化求导 |

Q 学习的是“原始动作经过完整执行流程后的结果”。每个样本保存原始坐标、合法化坐标、实际评估 DEF 和后端宏几何；后端轨道对齐可能再次移动宏块，因此导入前合法不等于导入后必然合法。

原始 FlowPlace 使用 20 步、带约束的生成流程。当前 FQL 的 BC flow 使用 10 步 Euler 积分给一步策略提供蒸馏目标，内部不逐步投影，最终再合法化。这是明确的方法差异，需要通过 BC 对照区分策略蒸馏和 Q 优化各自的影响。

每个在线阶段都会更新 flow、一步策略和 Q；失败动作可用于 Q 学习，但不作为行为模仿目标。两轮完成后，最终策略使用每种方法各 16 个新增标签。最后阶段另采集的 8 个样本不用于这两轮更新，不能计入最终策略的训练数据量。

四个评估噪声用于比较同一策略生成的不同布局，**不等于四次独立训练**。当前配置也只是初步实验，不代表已经训练收敛。

第一轮在线更新及实际布局评估均已完成：每种方法均使用 64 个原有标签和自身新增的 8 个标签。两种方法的 flow 和一步策略各有 207 个参数张量发生变化，Q 各有 16 个参数张量发生变化，说明实际更新了三个网络。

## 后端评估条件

各方法使用相同的 OpenROAD 流程、Nangate45 工艺、原生宏导入方式和 8 个 CPU 线程。当前后端环境固定为 ORFS 26Q4 镜像，完整版本和文件哈希保存在运行记录中。

完整评估从各自已经测量的 GRT 数据库继续详细布线，统一最多 20 轮修复，随后输出最终时序、功耗、面积和 DRC。这个统一对照与历史 Table 2 的 cap4 结果分开，旧 Table 2 作业继续暂停。

原定完整布线比较为原始 FlowPlace、离线 BC、离线 FQL、在线 BC、在线 FQL 各 4 个固定布局，加 1 个最佳 TRAIN 参考，共 21 个请求。成功但 DRC 非零的布局仍保留 DRC 数值，不能直接称为满足制造要求。

另有一个相同采集预算的搜索对照：每种方法从 64 个 TRAIN 和自身前两阶段的 16 个采集布局中，按实测 GRT 线长选择一个参考，再按相同条件详细布线。选择规则已固定，不使用评估噪声、验证标签或最终详细布线结果选布局。它用于判断收益是否超出了“多评估一些布局再保留最好结果”。

离线 FQL 的四个评估样本中，三个线长低于对应 BC，一个更高。离线策略的八个采集样本平均线长分别为 BC 2.2578 m、FQL 2.2674 m，尚未呈现一致改善。这些数据来自全局布线，详细布线 DRC 和最终 PPA 另行统计。

原始 FlowPlace 的平均线长和这些 PPA 指标仍优于离线 FQL。FQL 在四个评估样本上的 Q 预测均偏乐观，平均 reward 误差约 0.0259，对应约 0.0606 m 线长，超过当前相对 BC 的 0.0314 m 平均收益。下一步需要检查在线真实反馈能否改善这种校准误差。

第一轮在线 FQL 相比自身离线版，平均 GRT 线长下降约 **1.88%**；但 BC 也下降约 **2.98%**，在线两者的线长差距只剩约 **0.17%**。FQL 的平均 TNS 更接近零，标准单元面积则更大。因此目前不能把线长下降直接归因于 RL，也不能宣称全面 PPA 改善。这里的百分比均按各组均值之比计算，不是逐噪声百分比的平均。

第二轮在线 FQL 相比自身离线版的平均 GRT 线长下降约 **1.44%**，相比额外离线训练1200步的对照下降约 **1.91%**，但比同轮匹配 BC 高约 **1.39%**，四个配对噪声中只有一个优于 BC。第二轮 FQL 的 WNS/TNS 也更差。这支持继续研究真实反馈的作用，但不支持已经获得 RL 优势或全面 PPA 改善的结论。第二轮 FQL 的八个另行采集样本优于 BC 的均值不能替代预定评估组的结果。

另有四个固定噪声的诊断已完成：使用冻结的十步 BC flow 直接生成布局，跳过一步策略和 Q 引导，平均 GRT 线长为 **2.411552 m**。匹配一步 BC 比它高约 0.46%，离线 FQL 比它低约 0.84%。这组数据暂时不支持“一步蒸馏是主要质量损失来源”的判断；仍只有四个噪声，其反馈不进入训练。

固定布局上的 Q 检查也已跑通，CPU 重算复现了保存的神经 Q 误差。神经 Q 的训练 MAE 约 0.00013，验证 MAE 约 0.02558，说明训练集拟合精度不能代表新布局精度。只用 17 个物理特征的 ridge，在 FQL 的四个评估布局上 MAE 为 0.01397，低于神经 Q 的 0.02588；但在八个采集布局上反而更差（0.04988 对 0.02942）。因此不能仅凭四个评估布局就认定简单 critic 更好。正则强度只由 TRAIN 家族交叉验证选择，没有用这些评估结果调参。

固定布局检查让各阶段 Q 评估同一组布局，明确标出哪些采集样本已经进入训练，判断在线反馈是否改善了新布局上的误差。原策略、原 reward 和实际后端标签均保留。

第一轮检查已完成：在同一组新 FQL 评估布局上，旧 Q 的 MAE 为0.03798，更新后的 Q 为0.04609，误差没有下降。两者都没有用这些评估布局训练。新增8条采集数据尚不足以证明 Q 的泛化改善，需要继续检查第二轮及后续数据覆盖问题。

第二轮固定布局检查也已完成：让离线、第一轮和第二轮的 Q 评估同一组第二轮 FQL 布局，MAE 依次为 **0.02896、0.04028、0.04720**，排序相关依次为 **0.4、−0.4、−0.8**；这些布局从未进入训练。第二轮训练 MAE 约0.00016，远低于新布局误差。简单 ridge 在这一组上的排序同样不可靠，暂不支持直接换成 ridge 就能改善策略的判断。

后端重复性检查也已完成：固定离线 BC 与 FQL 的评估噪声0对应 DEF，各完整重跑3次 GRT。两组线长分别一直为2,437,719μm和2,415,323μm，全部记录的 PPA 和拥塞指标也与原测量一致。这只验证这两个固定输入下的当前工具/八线程流程，不等于策略在不同噪声或 seed 下稳定。

## 增加在线反馈覆盖的继续实验

前两轮每次只新增8个标签，Q 在两轮固定布局检查中的误差均未改善。因此继续检查数据覆盖是否不足，暂时保持网络、损失、学习率和每阶段600步更新不变。

固定第二轮的 BC/FQL checkpoint，各增加24个新采集布局，再加入上一轮已经采集、但未参与第二轮更新的8个布局。这样每种方法新增可用于训练的反馈是32个，累计在线标签由16增至48。56个采集及更新前评估请求、12个更新后评估请求均已获得成功的真实 GRT 结果。磁盘保护退出和抢占的请求已按原始布局单独恢复，不赋予物理失败奖励，也不重跑已成功的布局。三组继续训练均已完成600步；使用相同的 H20，父模型训练使用 L20，硬件差异单独记录。

## Q 的补充诊断

先检查能否用更受约束的回归模型缓解误差，没有直接替换策略。核回归的特征组合、长度尺度和正则强度只根据训练数据的五折家族交叉验证选择。对同一组第二轮 FQL 布局，使用80条训练数据的核模型 MAE 为0.04174，排序相关仍为−0.8；减去模型标准差后，偏差减小，但排序仍为−0.8。它在原验证集的误差约0.02751，不能说明能正确指导当前策略。因此没有据此启动新的核 Q 策略训练。

另做了只评分的坐标对照：训练和测试都使用合法化后的执行坐标，仍按同样的训练家族交叉验证选择核模型。第二轮模型在同一组 FQL 布局上的 MAE 为0.04130，排序相关−0.8；减去标准差后的 MAE 为0.03756，排序相关−1.0。这个对照没有改善排序，不能说明仅更换坐标表示就足以解决问题，也不涉及对合法化求解器求导。记录保存在 `graph_o2o_kernel_execution_diagnostic_v1/job_1792642/`。

进一步检查 Q 的局部方向是否正确：固定第二轮 FQL 的采集布局0–3，这四条数据都没有用于该轮 Q 的训练。每个布局分别沿 Q 梯度和固定随机方向，进行同样大小的正、负扰动，合计16个新后端请求。原始坐标的 RMS 扰动固定为0.02，随后使用同一个合法化与 GRT 流程；这些诊断反馈不进入 replay。

16个请求均已完成真实 GRT 评估。Q 梯度预测的正负方向与实际 reward 在四个邻域中只有两处一致；沿正 Q 方向移动后，只有一个布局优于原布局，四处平均 reward 反而下降约0.01115。这说明当前 Q 的局部引导还不可靠，但四个邻域不足以确定总体成功率，全部随机方向对照也保留在报告中。

几何数据还显示：布局0的 Q 方向正负扰动虽然都只有0.02，合法化后的位移 RMS 却分别约为0.151和0.115；其他几个布局大多在0.01左右。原始坐标的小幅变化可能引起较大的执行布局变化，需要结合实际 reward 判断，不能只靠预测值或训练 loss 判断方向是否有益。

## 需要继续核验的问题

1. 新采集的真实反馈是否降低了 Q 的预测误差，是否改变了后续策略产生的布局质量。
2. 合法化和后端轨道对齐改变坐标后，Q 是否仍能正确排序新布局。
3. 全局布线线长的改善能否延续到最终 rWL、DRC 和时序指标。
4. 策略是否优于同预算的最佳实测布局参考，并在更多训练 seed 上保持效果。

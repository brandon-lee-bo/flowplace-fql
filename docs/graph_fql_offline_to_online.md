# FlowPlace＋Flow-Q：离线到在线实验记录

当前结论：已经把 Flow-Q 的行为流、独立一步策略和 twin-Q 接入 FlowPlace 图网络，完成真实 offline → online 更新、两电路最终 PPA 和原生证据保存。bp_fe 三个训练 seed 的在线 FQL 平均线长比 BC 低0.308%，但两个 seed 更差；384标签组低1.388%，但TNS更差；bp_be低0.754%，但比自身离线版本线长高0.868%。后两组各只有一个训练seed，当前尚无稳定的整体PPA优势。

本文按当前方法和证据整理，逐次提交、报错及修订保留在 [运行账本](run_ledger.md)。旧 Table 2 复现任务继续暂停；这里统一使用的新后端配置不与旧表中的最好数字混合。

## 1. 实验想回答什么

主要问题是：在相同数据和更新预算下，加入 Q 优化是否比只做行为学习更好，以及新增真实后端反馈是否带来额外收益。不能把“比初始模型变好了”直接归因于 RL，也不能把从更多已测布局中选出一个好结果当成策略学得更好。

| 研究 | 真实离线 TRAIN 标签 | 训练 seed | 实际在线更新 | 当前评估状态 |
| --- | --- | --- | --- | --- |
| bp_fe 主实验 | 64 | 0、1、2 | 每组两轮，每轮8条自采反馈、600步更新 | 228/228 GRT；63/63预定最终布线请求成功，DRC均为0 |
| bp_fe 扩大标签 | 384 | 0 | 相同更新预算 | 76/76 GRT；21/21预定最终布线及2/2 best400对照均成功、DRC均为0，完整原生审计和持久保存完成 |
| bp_be 第二电路 | 64 | 0 | 相同更新预算 | 76/76 GRT；23/23最终布线成功、DRC均为0，独立审计、统一汇总和持久保存完成 |

四个生成噪声用于比较同一个策略产生的不同布局，不是四次独立训练。冻结的原始 FlowPlace 没有独立重训；共享参考布局的复用也不增加独立样本数。两个电路分别训练，不称为跨电路零样本迁移。

## 2. 方法：哪些复用，哪些改变

一次动作生成整张布局：bp_fe为11个宏块、22个坐标，bp_be为10个宏块、20个坐标。状态是固定电路及其设计上下文。动作经过合法化、DEF取整、后端轨道对齐、标准单元放置、CTS和GRT，得到一次终局反馈；flow的积分时间不是RL环境步骤。

终止mask为0，因此Q目标直接是本次实测reward，不对虚构的后续状态自举。这是Flow-Q的终局决策适配，保留其行为流、同噪声蒸馏与Q优化机制，不检验长序列Bellman信用分配。

| 部分 | 当前实现 | 来源及差异 |
| --- | --- | --- |
| 电路输入 | 宏尺寸、稀疏连接edge_index、引脚偏移、当前坐标及时间 | 复用FlowPlace；连接关系由图的边表示，不要求显式存一张稠密邻接矩阵 |
| 行为flow | GATv2＋全局自注意力＋MLP，预测宏坐标速度 | 加载公开预训练权重，继续flow matching训练 |
| 一步策略 | 从噪声直接输出完整布局的独立图网络 | 与行为flow相同骨干、独立参数，使用Flow-Q的蒸馏/Q目标 |
| 骨干配置 | hidden=256，GAT及全局注意力均4 heads，dropout=0，时间编码32维 | 沿用公开配置；每个图策略6,285,058个参数 |
| Q | 17个物理特征＋宏坐标，两个独立128宽MLP | 固定电路critic；输入维数为39或37，归一化仅由离线TRAIN决定 |
| 策略目标 | 10 × 同噪声蒸馏MSE − mean(Q1,Q2) | 匹配BC把Q项系数设为0，其余核心训练机制相同 |
| 原始FlowPlace推理 | 20步、生成过程中加入硬约束 | 保留为冻结基线 |
| FQL行为flow与策略推理 | teacher用10步Euler，内部不逐步投影；一步策略输出后统一合法化 | 是明确适配，不能声称完全照搬原始FlowPlace采样器 |
| 初始噪声 | Uniform[-1,1] | 与FlowPlace一致；原始FQL使用Gaussian |
| 在线采样 | 50%离线、50%已测在线数据 | 使用官方代码可选balanced sampling；FQL论文默认是合并后均匀采样 |

原始动作、合法化动作和实际评估DEF分别保存。Q预测的是“原始动作经过整个执行流程后的reward”，不假设硬合法化可导。策略更新通过学习到的Q求导，critic参数在该更新中冻结，teacher目标停止梯度；行为flow另行更新。

reward固定为负GRT线长除以离线TRAIN均值：bp_fe分母为2,341,121.25μm，bp_be为3,537,708.3125μm。验证、测试与在线数据不改变分母。时序、功耗和面积单独评估，没有混入当前reward。只有核实的终局物理/几何失败使用效用−4、PPA记缺失；基础设施、解析或存储错误不伪装成物理失败。

这不是自动学习reward函数。Q学习给定reward下布局的价值，当前优化目标仍由上述GRT线长定义。

## 3. 数据、初始化和实际训练

初始Q数据为64条真实TRAIN和16条验证标签，按噪声家族划分，验证不进入训练。行为flow另使用192条无后端标签的TRAIN teacher布局，合计256个行为目标；这些目标不是额外的真实PPA标签。

扩大标签组对其余160个TRAIN家族各增加两个既有布局的真实GRT评分，320/320成功，使Q标签从64增至384。行为目标仍为256个。新增标签也改变Q的TRAIN特征归一化，因此不是“只加样本、所有统计量不变”的对照，其评分预算也更大。

| 配置 | 实际设置 |
| --- | --- |
| 初始化 | 两个图网络均从同一公开FlowPlace权重初始化，随后独立更新；每个训练seed具有自己的共同预热结果 |
| 共同预热 | flow 300步，一步策略蒸馏800步，Q回归2000步 |
| 离线训练 | BC、FQL各1000步，共同初始化及相同数据预算 |
| 在线训练 | 两轮，各自每轮采集8条真实反馈，再更新600步 |
| Optimizer | flow/actor用Adam，学习率1e-5；Q用AdamW，学习率3e-4、weight decay=1e-4 |
| Batch size | 常规更新16；Q共同预热64 |
| 梯度处理 | 各模块梯度范数裁剪至1；非有限loss/梯度报错 |
| 更新比例 | 常规每步各更新actor、行为flow和Q一次 |
| Checkpoint | 每250步及阶段末保存；评估固定使用阶段最后一步，不按最好噪声或PPA挑选 |
| 训练seed | 主实验0、1、2；扩大标签及第二电路各seed0 |
| 评估噪声 | seed=900000产生四个固定噪声，各方法配对 |
| 采集噪声 | 随训练seed及轮次改变；反馈只加入对应方法的replay |
| 计算环境 | GPU训练通过Slurm；主线使用L20，部分后续控制使用H20，逐作业保留实际硬件 |

每个阶段各方法导出8个collect和4个evaluation布局，离线阶段另有4个冻结FlowPlace参考，共28＋24＋24=76个GRT请求。只有前两阶段collect进入最终两轮更新，所以最终策略各实际使用16条在线标签；最后额外生成的8条不算该checkpoint的训练数据。

每轮确实更新flow、actor和critic，不是只做候选筛选。独立父子checkpoint审计重新读取实际张量、迭代和replay，核验新阶段各有207/207/16个参数张量变化。较早seed0的两份历史记录未记录父哈希，当前只从保留权重重算，未补写历史字段。

全部五组训练的30个方法/阶段、440个日志点与15个实际训练作业已核验保存。蒸馏MSE总体下降，但行为flow的单批次loss仍有波动；没有据此宣称训练收敛。每个曲线点是50步记录一次的mini-batch值，不是全数据集误差。

## 7. 有信息量的控制与机制诊断

### 继续训练、更多反馈与最佳实测参考

从seed0离线FQL出发，仅用原数据额外训练1200步，四个最终布局DRC均为0，平均rWL为2.083242m。相同seed的在线FQL为2.034085m，匹配在线BC为2.007945m。因此真实反馈/继续更新可能有帮助，但不能证明Q优于BC。

同采集预算直接保留最佳实测布局的参考，seed0原64标签组的BC/FQL最终rWL为1.802668/1.793929m，均DRC=0。它们明显好于各自策略均值，但每组只有一个经GRT选出的布局，不当成生成策略的平均能力。

### 采样和后端是否造成假信号

冻结10步行为flow直接生成的四噪声GRT均值2.411552m，匹配一步BC为2.422601m，差约0.46%。这是一个小诊断，不支持把一步蒸馏直接认定为主要质量瓶颈。

两个固定BC/FQL输入各完整重跑3次GRT，所有记录PPA与拥塞指标均相同。bulk/scratch存储切换对相同输入的GRT、DRT也核验一致；只说明这些固定输入下流程可复现，不说明跨seed稳定。

GRT→DRT诊断覆盖83个请求，全部成功。80次策略评估按执行坐标去重后为72种布局，线长Pearson为0.99842，Spearman为0.99733；36对BC/FQL中35对改善方向一致。唯一反向案例的差异小于0.1%，所以高整体相关也不能保证每个微小局部收益。该结论限于已测bp_fe分布，不证明其他电路或时序/功耗同样受益。

## 9. 本轮结论与局限

方法接入和真实offline→online循环已完成，当前主要证据指向Q在策略新提案上的可靠性不足，同时行为反馈的使用方式也会影响结果。多加标签、减小预测误差或继续训练，都没有自动转化为稳定优势。

| 实验 | 在线FQL相对同期BC最终线长 | 结论边界 |
| --- | --- | --- |
| bp_fe，64标签、三个训练seed | −0.308% | 两个seed更差，不能证明稳定收益 |
| bp_fe，384标签、一个训练seed | −1.388% | WNS略好、TNS更差，同提案Q排序未改善 |
| bp_be，64标签、一个训练seed | −0.754% | 同期BC较差，但FQL自身在线后仍退步 |

本轮接入、实际离线及在线训练、完整最终PPA、机制控制和原生证据保存均已完成。结果支持“方法已实际运行并得到可追溯比较”，尚不支持稳定RL优势、全面PPA改善、跨电路零样本泛化或训练已收敛。旧Table2任务继续保持暂停。

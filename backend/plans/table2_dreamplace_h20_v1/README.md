# Frozen DREAMPlace H20 generation cohort

Six designs, one H20, serial fresh processes, seed 1000 and the original per-design author halo values. All coordinates are reinitialized; stock public BB/two-stage placement and original legalizers are unchanged. `bp_fe` reuses the predeclared successful GPU smoke `dmp_public41_gpu_bp_fe_smoke_v2` (job 1788008); the failed v1 startup is retained. No other candidates or seeds are searched.

`tasks.jsonl` freezes runner/installation identities, released DEF hashes, author configs, libraries and SDCs. Config copies and the actual installation file hashes are included. The driver verifies these before execution and validates complete generation manifests afterward. Failed designs remain in the six-design denominator. Only generation runs here; the root agent must freeze the same final OpenROAD tool/flow for both methods before evaluating PPA.

The implementation is an explicitly derived public DREAMPlace 4.1 baseline. Missing original replace.def, author baseline settings and exact strong-legalizer correspondence remain limitations. CPU smoke, failed imports and GPU build compatibility history are retained separately; H20 runtime is not a claim about the paper's hardware.
